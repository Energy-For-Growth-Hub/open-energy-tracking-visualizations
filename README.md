# Open Energy Tracking Visualizations

This repository contains D3 visualization prototypes and templates for the Open Energy Tracking microsite.

## Repository Structure

- `data/`  
  Master data files used by the visualizations.

- `templates/`  
  Reusable D3 visualization templates and current prototypes.

- `docs/`  
  Documentation, workflow notes, and maintenance guides.

## Current Visualization Templates

- Donut chart
- Slope chart
- Global navigation map
- Stacked bar chart

## Long-Term Goal

The long-term goal is to move from country-specific prototypes to reusable visualization templates that read from centralized data files.

Eventually, each chart should be able to dynamically display the correct country based on a country slug or URL parameter, rather than requiring separate files for every country.
