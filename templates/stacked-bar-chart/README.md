# Stacked Bar Chart

Current status: Prototype.

Files:
- index.html: chart container and styling
- script.js: D3 visualization logic
- sample_data.csv: sample country-level tier distribution data used during prototype development

Purpose:
Compare the distribution of population across MTF electricity consumption tiers for multiple countries in a single view.

Key Features:
- Tier-based color coding
- Country comparison
- Population share visualization
- Interactive tooltips
- Sortable and expandable design potential

Future goal:
Convert the prototype into a reusable template that reads from centralized country data. The visualization should support dynamic country selection, filtering, and automated updates as new electricity consumption estimates become available.
