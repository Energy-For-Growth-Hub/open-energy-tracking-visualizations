# Slope Chart

Current status: Senegal prototype.

Files:
- index.html: chart container and styling
- script.js: D3 visualization logic
- senegal_slope_chart.csv: sample data used during prototype development

Purpose:
Visualize changes in the share of the population across electricity consumption tiers between two selected years.

Future goal:
Convert this prototype into a reusable country template that reads from a centralized data file and dynamically loads the requested country. The same visualization should be capable of displaying any country in the Open Energy Tracking database without requiring country-specific code.
